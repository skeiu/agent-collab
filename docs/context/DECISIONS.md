## 被否决的替代方案

| 替代方案 | 改用 | 理由 | 来源 |
|---|---|---|---|
| 基于 `standard` 派生 `agent-collab` 预设（PLAN.md §9.5 原“首选”） | 整份复制 `standard` | 实测不可行：`dsh-agent-preset` 没有继承字段，补丁改不到 `standard` 内部的行 | 1a 第 1 批实验 01 |
| dsh 执行端默认用用户选的预设、靠任务书约束并转发提问 | 整份复制 `standard`；此做法降为复制品不可用时的退回方案 | 用户选择从机制上保证执行端不直接问人（D11） | 用户，2026-10-23 |
| 用 dsh headless 模式派发任务并实时查看 | D4：写 dsh 桥接插件 | 实测中 headless 会话在 dsh Web 里不实时刷新，运行中被误显示为“已停止”；在 Web 里打开后，Web 占住写锁，`--session-id` 续接失败 | PLAN.md §5.1、附录 A.2 |
| 随仓库附带 `@agentclientprotocol/sdk` | 自写精简 ACP（JSON-RPC over ndjson），客户端和桥接各一份 | 用到的方法不到 10 个；免去附带第三方代码和许可证处理 | 用户，2026-10-23（1a 实现决定 1） |
| acp 覆盖层用自写的限定 YAML 解析器，或附带第三方 YAML 库 | 借用 dsh 安装目录里自带的 `yaml` 包 | 这条路径只在 dsh 存在时运行，格式与 dsh 自己的解析一致；不引入依赖 | 用户，2026-10-23（1a 实现决定 2） |
| 字段级接口契约写进 PLAN.md | 单独的 `docs/protocol.md`，PLAN.md 链接 | PLAN.md 已约 1000 行；字段约定改动频繁 | 用户，2026-10-23（1a 实现决定 3） |
| 桥接和端到端测试全部用真实模型 | 本地假 LLM 服务（OpenAI 兼容接口，按脚本返回）；真实模型只用于 T11、T13；探针不成立时退回真实模型 | 确定、可重复、不花 token | 用户，2026-10-23（1a 实现决定 4） |
| 所有配置项都允许项目级覆盖 | 权限和执行环境类的项不允许出现在 `.agent-collab.json` | 项目文件随仓库来，可能不可信 | 用户，2026-10-23（1a 实现决定 7） |
| 这 4 项和决定 7 的项一样，完全不允许项目级设置 | 项目级只能收紧 | 仓库仍能声明自己的保护路径、要求更严的确认；放宽的路被堵住 | 用户，2026-10-23 |
